# 🚀 Seeker Streaks

**A daily commitment layer for Solana Mobile users**

Seeker Streaks is a mobile-first Web3 commitment app built for the Solana Mobile ecosystem.  
Users connect and verify their wallet, check in once per day, maintain streaks, and track their position on a public leaderboard.

Built for the **MONOLITH — Solana Mobile Hackathon by Solana Mobile × RadiantsDAO**.

---

## 🔥 Core Idea

Consistency is identity.

Seeker Streaks transforms wallet ownership into a daily ritual.  
The system emphasizes long-term consistency over short-term activity, creating a visible signal of commitment within the Seeker community.

## 📱 Features

- 🔐 Secure wallet authentication
- 🧾 Nonce-based verification (no private data exposed)
- 📅 Daily UTC check-in system
- 🔁 Deterministic streak tracking
- 🏆 Leaderboard ranked by longest streak
- 🪪 .skr name resolution
- ⚡ Mobile-first UI optimized for Solana Seeker devices

## 🧠 Behavioral Design Focus

The system is intentionally minimal:

Check in → Maintain streak → Protect streak → Climb leaderboard

By reducing friction and emphasizing continuity, the app encourages long-term participation rather than one-time interaction.
